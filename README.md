# test-forge

Calibrate, build, and refine tests and validators around real failure consequences, independent criteria, and the least burdensome trustworthy evidence.

## Use

> Review whether these tests detect the failures that matter, and improve the weak checks without adding redundant work.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `test-forge/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
